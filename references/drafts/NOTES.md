## The judge

Every take was judged blind by one fresh agent that had not seen the brief. Each judge was a new agent started in its own sandbox, so it could not see this repo, the brief, the prompt, the model name or the other takes. It was given one attachment, a copy of the take named `image.png` with the same pixels and all metadata removed, and the text below, with nothing added. Judges were started with neutral names (`image_viewer_NN`). Each got ten minutes and one replacement.

The text each judge received, exactly:

> You will see one image. Which of these is it most likely to be? (a) a frame from a top-budget film or a cinema nature documentary, (b) a stock photograph, (c) a seed catalog or textbook picture, (d) amateur generated art, (e) a 3D render. Answer with one letter and name its weakest part.

Only (a) passes.
